This proposal follows natural A5 integration acceptance; it does not authorize
or start a formal matrix. The original16 v1.1 formal slots remain permanently
excluded from final v1.2 statistics. Pilot-1 and Pilot-2 retain their original
development classifications. No formal sample size is selected here.

## Small paired validation

Propose **six method attempts**: one fresh scene seed in each existing
Easy/Moderate/Hard tier, each run by Generic NBV and Ours. This checks the shared
v1.2 integration on unseen scenes; it cannot establish comparative superiority
or estimate a reliable formal sample size. Existing synthetic and Hard-002
recorded regressions separately exercise the known geometric mechanism.

Before either method runs, draw and record all three new seeds using the
existing scene distribution, excluding previously used seeds. Keep the original
generation rules. Freeze their geometry and balanced/random method order before
any scores, candidate counts or outcomes are observed. Apply only the existing
method-independent depth/FOV, initial ground-return and physical-setup
admissibility checks. Retain setup failures and reasons. A true setup-domain
conflict requires review, not seed replacement; a proven invalid platform
activation can be repeated. Never redraw because a scene lacks a rescue case
or favors one method.

Use the frozen common experimental initial pose `(-1.4,0,1.2,0)`, not the distinct
original natural A5 regression pose. Keep three observation windows, the4.0m observer
gate, v1.1 association allowance, all thresholds/costs/selection and success
criteria. Generic/Ours share viewpoints, visibility/occlusion, A2 updater,
exact-winner support, operational gate, stopping, Ground selection and execution.
Only generic versus task observation weighting differs.

## Record and review

- Paired E2E outcomes, especially discordant pairs, with no pilot significance
  claim. `confirmed → D_exec → retrieval` and original failure taxonomy.
- Observation windows, first confirmation/discovery, and robot distance/time
  measured in simulation time; report engineering wall time separately.
- TARGET/ENVIRONMENT/AMBIGUOUS evidence, raw-grid versus operational blocking,
  true target intersections, actual ground-support deficits and confirmation.
- Per-cell winner-blocked/non-winner-unblocked diagnostics including IDs and
  ground support. Do not use these alternatives for policy reselection.
- Same-state Generic/Ours candidate, visibility, cost and formula checks.
- All genuine failures remain failures; only protocol-defined invalid platform
  trials may be rerun, with the original record preserved.

Stop for research review if exact-winner support exhibits a new structural
deadlock, fairness cannot be maintained, or a fix would alter frozen method or
protocol semantics. A few unsuccessful executions are not permission to tune
parameters or replace seeds. Review these six paired-validation attempts before
any final formal plan; do not resume the historical560-slot sequence.
